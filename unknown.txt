
## Testing PWA Installation

### Desktop (Chrome/Edge)

1. Open the application in Chrome or Edge
2. Look for the install icon in the address bar (⊕ or computer icon)
3. Click it and follow the prompts
4. The app should open in a standalone window

### Android

1. Open the application in Chrome
2. Tap the menu (⋮) in the top-right
3. Select "Add to Home Screen" or "Install App"
4. Follow the prompts
5. The app icon should appear on your home screen

### iOS (Safari)

1. Open the application in Safari
2. Tap the Share button (square with arrow)
3. Scroll down and tap "Add to Home Screen"
4. Customize the name if desired
5. Tap "Add"
6. The app icon should appear on your home screen

## Verification Checklist

- [ ] App installs successfully on desktop

## Troubleshooting

### Icons Not Showing
- Verify icon files exist in `public/assets/`
- Check browser console for 404 errors
- Clear browser cache and reload

### Service Worker Not Registering
- Check browser console for errors
- Ensure HTTPS is enabled (required for PWA)
- Verify `sw.js` is accessible at `/sw.js`

### Install Prompt Not Appearing
- PWA criteria must be met (manifest, service worker, HTTPS)
- Some browsers don't show prompt immediately
- User may have dismissed it previously

### Offline Mode Not Working
- Check service worker is active in DevTools
- Verify assets are cached (Application > Cache Storage)
- Test with DevTools offline mode
